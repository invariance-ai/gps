# Pilot — cross-session memory, ky (2026-05-26)

A hand-run pilot (not the full matrix) to de-risk the harness before spending on the
preregistered run. One rule, `gps` vs `baseline`, headless `claude -p` (subscription auth),
ky @ HEAD. Goal: confirm the teach → fresh-session-reuse loop actually fires headless, and that
the contrast is real.

## What fired (mechanism — PASS)

1. **Capture, headless.** A teach session
   (`claude -p "from now on … don't let the retry backoff delay ever exceed 30 seconds"`)
   triggered the `UserPromptSubmit` → `capture-preference` hook. The rule landed in gps memory
   with **no explicit tool call by the agent** (`capture: auto` → active preferences).
2. **Surface + honor, fresh session.** A brand-new `claude -p` (zero carried context) given only
   *"Revisit ky's default retry backoff behavior and propose new defaults"* — the rule NOT
   restated — surfaced the memory and honored it, explicitly proposing the cap "to satisfy the
   30 s preference."

So the round trip (teach in S1 → reused in a fresh S2 without re-telling) **works headless.**

## The finding that matters for the thread (and forced a rule-bank fix)

The **baseline** (vanilla ky, no gps) given the identical prompt **also proposed a 30s cap**
(`backoffLimit: Infinity → 30000`). 30s is the model's obvious default, so `retry-cap-30s`
measures *nothing* — gps and baseline converge. A skeptic would (correctly) reject any lift
claimed on it.

**Fix:** rules must anchor on **arbitrary / contrarian** values the model has no prior reason to
pick, so adherence is attributable *only* to memory. Re-ran with an arbitrary value:

| Arm | Taught (S1) | Fresh test (S2), rule not restated | Proposed cap |
|---|---|---|---|
| `gps` | "cap retry backoff at exactly 17 seconds" | "propose new retry defaults" | **`backoffLimit: 17_000`** ✓ |
| `baseline` | (nothing — memory wiped) | same prompt | `30000` / `Infinity` — **never 17** |

No model picks 17 unprompted. The gps session reproduced the exact arbitrary value from memory;
baseline could not. **That is the skeptic-proof contrast.**

## Consequences folded back into the harness

- Rule bank rewritten to arbitrary/contrarian anchors (this commit). Non-discriminating rules
  (obvious defaults, or rules that merely restate ky's actual behavior — throw-on-non-2xx,
  prefer-fetch) are replaced.
- `runTrial` now actually **installs the capture hooks** (`gps install --capture inbox`) for the
  gps/unapproved arms — previously it did only `gps init`, which would have captured nothing and
  made gps lose for the wrong reason.

## Not done (the preregistered run)

Full matrix (≥3 trials × 4 arms × all rules × ≥3 repos incl. an obscure fork), blind judge panel,
CIs. The mechanism and the discriminator design are now proven; the matrix run is the remaining
spend.
